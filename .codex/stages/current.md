# Поддержка WebApp — 2026-11-25

Цель — улучшить ответы в существующем чате на основе полной истории кабинета. Экономный режим, без субагентов. Источник — production SQLite, чтение всех 105 сообщений в 12 диалогах. Роли берутся из поля отправителя, поэтому исторические пометки не доказывают, кто написал каждое сообщение. Переписка из отдельных личных чатов Telegram в этом источнике отсутствует.

| Сценарий | Ожидаемое поведение | Проверка |
| --- | --- | --- |
| XrayCore, geosite.dat, ошибка внутри Happ со словом Telegram | Диагностика запуска ядра, запрос ОС и версии Happ, передача менеджеру | Regression test, provider mock |
| Не обновился остаток, непонятный «0 — бесконечность», неизвестный тариф, оплата или обещание менеджера | Не гадать о значении, не советовать повторную покупку, передать менеджеру | Regression tests |
| Как проверить/выключить автопродление | Настройки → Автопродление, текущая подписка действует до конца; без заявления о состоянии аккаунта | Regression tests и сверка с экраном |
| Работают другие сайты, известны название сервиса или VPN-клиент | Учитывать названное, не выдумывать страны и причину недоступности | Проверка системного контекста |
| Менеджер владеет обращением, провайдер недоступен, новый запрос во время генерации | Существующие транзакции, пауза, лимиты и очередь сохраняются | Имеющиеся тесты |
| OpenCode | Фиксированный HTTPS inference endpoint, синтетическая проверка протокола; боевое переключение после подтверждения доступа и теста на эталонах | Mock запроса. Без ключа сохраняется активный Groq |

Компоненты: bot/services/support_ai.py, знания поддержки, сфокусированные тесты, отчет об истории, документация провайдера. Интерфейс и API-контракт чата сохраняются. Архив с очищенными текстами хранится на сервере с доступом root; в Git только сводка и общие правила. Модель получает только текущую очищенную переписку и проверенные продуктовые знания. На проде перезапускается только API подписки. Откат — revert и перезапуск API, данные чатов не восстанавливаются из архива.

## Результат и проверка

- 96 тестов поддержки прошли в изолированном checkout с тестовой конфигурацией. Два дополнительных запроса POST → GET с тестовой авторизацией подтвердили сохранение ответа об автопродлении и отметку передачи ошибки XrayCore менеджеру.
- Продакшен: коммит `c65ad808` отправлен в main и применён через fast-forward. Перезапущен только API подписки. Оба сервиса active, API running без повторных запусков. Три проверенных сценария и один живой запрос к Groq на синтетических данных прошли. Сообщения реальным пользователям не отправлялись.
- `sub.arccnet.space`: кабинет 200 и показал экран входа в браузере, health 200, неавторизованный запрос к чату 401. Для отдельного имени `arccnet.space` обнаружен просроченный TLS-сертификат. Проверка чата с тестовой авторизацией выполнена на изолированной копии.
- Активен GPT-OSS 120B в Groq. OpenCode Go вернул 401. Адаптер Console проверен с имитацией ответа. Для переключения нужен действующий ключ Console, затем сравнение на синтетических сценариях. Альтернативы Groq не дали основания менять действующую модель.
- [Аудит истории поддержки](../../docs/operations/support-audit-20261125.md) описывает границы выборки, выводы и расположение защищённого архива.
