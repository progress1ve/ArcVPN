# Вызов менеджера и документация клиентов — 2026-11-25

Запрос владельца и скриншот задают расположение. В открытом чате одна кнопка «Позвать менеджера» сразу под последним ответом ИИ. Пока запрос выполняется, кнопка отключена. После принятия под ответом остаётся статус «Менеджер приглашён». При сбое показать сообщение рядом с кнопкой и сохранить возможность повтора. Ввод и черновик остаются доступны. На месте приглашения используется и текущий статус переданного диалога. Для закрытого диалога или если уже ответил менеджер, кнопка скрыта.

POST /api/support/manager принимает целое message_id последнего ответа ИИ в активном обращении текущего пользователя. Транзакция сохраняет передачу, подавляет зависшую генерацию и повторную отправку заявки. Если ИИ уже пометил обращение как требующее менеджера, явный вызов остаётся доступен. По первому принятому запросу используется текущая адресация уведомлений поддержки. Исправить геоданные автоматически кнопка не пытается.

Поиск по коротким проверенным выдержкам официальных руководств Happ и INCY добавляет подходящие материалы к текущему запросу. Произвольные адреса из чата не запрашиваются. Для geosite.dat объяснить несоответствие правила и файла и дать один подтверждённый шаг для известного клиента. XrayCore без текста ошибки запрашивает точную ошибку. Источник проверить по клиенту и показать ссылку. Смена провайдера OpenCode зависит от доступного ключа Console и теста. Не менять подключение или конфигурацию узлов.

Проверка: авторизация, чужой/устаревший ответ, повтор, поздняя генерация, закрытый чат, уже переданное обращение, интерфейс на 360/768/1280/1600, сборка клиента и совместимость старых ассетов, публичный API. Проверки отправки ведутся на тестовых данных без уведомлений реальных менеджеров. Откат — revert, восстановление прежней сборки и перезапуск API. Состояние уже переданных обращений сохраняется.
