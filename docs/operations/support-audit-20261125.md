По отметкам базы — 50 сообщений клиентов, 13 ответов менеджера в 7 диалогах и 42 сообщения с признаком ИИ. В истории есть тестовые строки и ранняя реплика с признаком ИИ, где автор представился менеджером. Числа отражают данные базы. Личные переписки в мессенджерах в этот срез не входят.

Копия всех сообщений с удалёнными идентификаторами участников и маскировкой типовых секретов хранится на сервере управления в `/root/arcvpn-support-audits/webapp-20261125.json` (0600). В текстах может остаться частный контекст. Копия используется для ретроспективы и не подключена к модели. При запросе модель получает проверенные общие сведения и только ограниченную историю своего диалога.

### Модель

Доступный локальный OpenCode Go вернул HTTP 401 на нейтральный запрос. Документация Go описывает трафик кодинг-агентов. Для обычного чата добавлен отдельный адаптер OpenCode Console по тарифу с оплатой за запросы. Формат запроса проверен тестом с имитацией провайдера, боевой ключ Console не найден в конфигурации поддержки. [OpenCode Go](https://opencode.ai/docs/console/go/) · [OpenCode Console inference](https://opencode.ai/docs/console/api/inference/)

Проверка исходных ответов на трёх синтетических сценариях с продакшен-доступом Groq: GPT-OSS 120B и GPT-OSS 20B ответили на все три, Qwen 3.8 27B на третий вернул 429. В ответах всех моделей встретились придуманные локации, пути меню или причины сбоя. Для распознанных случаев отвечают сверенные правила. Для остальных сохранён действующий GPT-OSS 120B, пока нет проверенной замены.
