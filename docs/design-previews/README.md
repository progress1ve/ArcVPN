# Design previews

Static references for ArcVPN UI decisions. They are documentation, not runtime assets.

- `flow-*` and `home-*` are July 2026 WebApp direction studies.
- `archive/admin-home-v*.png` preserves earlier admin/home iterations for visual regression context.

Production images belong under `bot/assets/` or `webapp/public/assets/`. New screenshots should be added here only when they document an accepted decision or a reproducible visual defect.
