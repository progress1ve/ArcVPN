# ArcVPN WebApp v2 — план разработки

Обновлено: 2026-07-29
Статус: локальная реализация `Arc Flow`, прод не изменяем.

## 1. Цель

Перенести весь пользовательский интерфейс ArcVPN из Telegram-бота в WebApp. В боте оставить:

- приветствие;
- обязательную проверку подписки на канал;
- одну кнопку «Подключиться», открывающую WebApp;
- существующую админ-панель и её обработчики.

WebApp должна стать единственным пользовательским кабинетом: подписка, подключение VPN, трафик, устройства, рефералы, поддержка и настройки.

## 3. Запуск внутри Telegram

Официальная документация:

- Telegram Mini Apps: https://core.telegram.org/bots/webapps
- Direct Mini App links: https://core.telegram.org/api/links
- Menu Button: https://core.telegram.org/api/bots/menu

### 3.1. Menu Button

Menu Button настраивается на HTTPS URL WebApp через BotFather или `setChatMenuButton`.

При старте WebApp:

1. вызвать `Telegram.WebApp.ready()`;
2. вызвать `Telegram.WebApp.expand()` как совместимый fallback;
3. установить `headerColor`, `backgroundColor` и `bottomBarColor` под тёмную тему;
4. если `Telegram.WebApp.isVersionAtLeast('8.0')`, вызвать `requestFullscreen()`;
5. обработать `fullscreenChanged` и `fullscreenFailed`;
6. использовать `safeAreaInset` и `contentSafeAreaInset`, чтобы интерфейс не попадал под вырез экрана, системную строку и элементы Telegram;
7. для мобильных устройств зафиксировать portrait через `lockOrientation()`, если это не ухудшит работу на планшетах.

Fallback: если fullscreen не поддерживается, приложение остаётся развёрнутым на полную доступную высоту через `expand()`.

### 3.2. Inline-кнопка в сообщении бота

Для нужного Telegram-вида используем кнопку типа `url`, ведущую на Direct Mini App link:

```text
https://t.me/<bot_username>/<app_short_name>?startapp=home&mode=fullscreen
```

Это не `web_app` URL-кнопка. Для direct link заранее настраивается Main Mini App и `app_short_name` в BotFather.

Для будущей маршрутизации можно передавать:

- `startapp=home`;
- `startapp=connect`;
- `startapp=referral`;
- `startapp=support`;
- `startapp=settings`.

WebApp читает `tgWebAppStartParam`, валидирует разрешённые значения и открывает нужную вкладку. Неизвестное значение ведёт на главную.

## 4. Haptic Feedback

Используется официальный `Telegram.WebApp.HapticFeedback`.

- Переключение нижней вкладки: `selectionChanged()`.
- Нажатие основной CTA: `impactOccurred('light')`.
- Успешная оплата, привязка email, отправка обращения: `notificationOccurred('success')`.
- Ошибка операции: `notificationOccurred('error')`.
- Предупреждение перед рискованным действием: `notificationOccurred('warning')`.

Вибрация вызывается только один раз на реальное изменение вкладки. Повторное нажатие активной вкладки не вибрирует.

## 5. Информационная архитектура

Нижняя навигация содержит ровно четыре раздела:

1. Главная.
2. Друзья.
3. Поддержка.
4. Настройки.

Навигация закреплена снизу, учитывает safe-area и имеет tap-target не меньше 44×44 px. Светлая тема удаляется.

## 6. Главная

### Обязательные блоки

- остаток дней и дата окончания;
- статус: trial / активна / скоро закончится / закончилась;
- «Продлить подписку»;
- «Подключить VPN»;
- количество устройств;
- обычный трафик: использовано / осталось;
- LTE/обход глушилок: использовано / осталось;
- карточка «Пригласи друга»;
- карточка «Поддержка».

### Состояния

- Новый пользователь: автоматически выдан trial, основная CTA — подключить VPN.
- Trial: срок и трафик trial, CTA подключения и покупки.
- Активная подписка: срок, трафик, устройства, продление.
- Скоро закончится: предупреждение и визуальный приоритет продления.
- Истекла: функции подключения недоступны, основная CTA — оплатить/продлить.
- Ошибка API: сохранённый каркас экрана, retry без полного зависания WebApp.

### Технический долг

Раздельные цифры обычного и LTE-трафика нельзя подменять общей квотой. До UI-реализации проверить, отдаёт ли 3x-ui корректную статистику по каждому inbound. Если нет — добавить серверную агрегацию по группам inbound:

- `regular`: XHTTP, TCP Reality, Hysteria2;
- `lte`: оба inbound «Обход глушилок (LTE)».

## 9. Настройки

### Аккаунт

- Telegram привязан всегда;
- email можно привязать к существующему аккаунту без регистрации;
- подтверждение владения email одноразовым кодом;
- вход по email не создаёт второй профиль и не дублирует подписку;
- отвязка email требует повторного подтверждения.

### Устройства

Текущий подсчёт по публичным IP не считается надёжным реестром устройств. До реализации раздела нужна отдельная модель устройств:

- стабильный идентификатор установки;
- платформа и версия ОС;
- модель только если Telegram/платформа действительно её предоставляет;
- дата первого и последнего подключения;
- имя, заданное пользователем;
- отзыв доступа конкретного устройства;
- лимит устройств и понятное состояние превышения.

Не определять выдуманную модель устройства по IP/User-Agent.

### Информация

- версия WebApp;
- контакты поддержки.

## 10. Дизайн-система

- только тёмная тема;
- mobile-first от ширины 375 px;
- сетка 8 px;
- основные отступы: 8, 12, 16, 24, 32 px;
- tap-target не меньше 44×44 px;
- одна акцентная палитра ArcVPN;
- максимум четыре размера шрифта и два основных веса;
- нижняя навигация и основные CTA находятся в thumb-zone;
- мягкие границы и подсветка без чрезмерного glow/blur;
- референсы VPNUS используются для композиции, расстояний и иерархии, но не для копирования бренда и графических ассетов.

### 10.1. Предлагаемое направление: Arc Material (на согласовании)

Не копировать VPNUS целиком. Использовать его удачные UX-паттерны — крупную нижнюю навигацию, ясную вертикальную иерархию, большие CTA и парные карточки — но построить собственный визуальный язык вокруг нового знака ArcVPN.

Основной вариант:

- фон: почти чёрный холодный графит/сине-чёрный;
- поверхности: тёмно-синие карточки с тонкой светлой границей;
- акцент: электрический голубой, использующий оттенки нового логотипа;
- белый логотип без постоянной подложки; синий градиент — только для splash/hero и очень мягких локальных glow;
- геометрические фоновые формы строятся из фрагментов нового знака, с opacity 3–6%;
- без тяжёлого glassmorphism и без 3D-рендеров на каждой карточке;
- карточки и кнопки материальные по композиции: крупные плоскости, радиус 20–28 px, ясные уровни, минимум теней.

Типографика:

- `Unbounded` — логотип/wordmark, крупное число оставшихся дней, короткие заголовки и номера шагов;
- `Inter` — кнопки, подписи, FAQ, чат, настройки и весь длинный текст;
- не использовать `Unbounded` в мелких подписях и длинных строках: на ширине 375 px он быстро ухудшает читаемость;
- загрузить шрифты локально в WebApp, чтобы интерфейс не зависел от Google Fonts и блокировок.

Предварительные токены:

```text
background       #060A12
surface          #0C1422
surface-raised   #111D2D
border           rgba(157, 204, 255, 0.12)
text             #F7FAFF
text-muted       #8FA2B8
accent           #48B8FF
accent-strong    #168DFF
success          #49D39A
warning          #FFB454
danger           #FF6678
```

Новый знак:

- полноразмерный PNG с синим фоном подходит для splash/loading и promo;
- прозрачный WebP подходит для hero/header;
- для favicon, Menu Button preview, нижней навигации и масштабирования нужен SVG/master-vector;
- до утверждения проверить упрощённый знак на размерах 20, 24, 32 и 48 px: центральный просвет не должен исчезать;
- нужен отдельный горизонтальный wordmark `ArcVPN`, совместимый со знаком.

Альтернативы для сравнения:

1. `Arc Material Blue` — рекомендуемый холодный сине-графитовый вариант.
2. `Arc Mono` — почти чёрно-белый интерфейс, голубой только в активных состояниях; строже и дороже визуально.
3. `Warm Material` — коричнево-песочная палитра референса; характерная, но менее подходящая для VPN-продукта и нового синего логотипа.
